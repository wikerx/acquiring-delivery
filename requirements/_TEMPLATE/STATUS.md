# 需求状态

## 文档目的

记录单个需求从接收到关闭的状态、负责人、分支、交付物、风险和下一步动作。

## 填写责任

需求负责人维护总体状态；阶段负责人更新各自交付进展；发布负责人关闭前复核。

## 输入资料

- `01-requirement/` 至 `05-release/` 阶段文档。
- Codex 任务交接记录、测试结果、评审结论和发布确认。
- Git 分支、Worktree、Pull Request 或 Merge Request 信息。
