# 需求交付目录说明

## 文档目的

说明单个需求交付目录的结构、阶段文档和维护规则，作为创建具体 `REQ-XXX` 需求目录时的复制模板。

## 填写责任

需求负责人初始化目录；各阶段负责人维护对应阶段文件；发布负责人关闭前复核完整性。

## 输入资料

- 原始需求、业务背景和人工确认记录。
- `platform/` 项目基线、`standards/` 质量门禁、`workflows/` 流程规范。
- 后端、前端、SDK、测试和发布相关交接记录。

## 必填内容

- 需求编号、需求名称、目标系统和影响范围。
- 各阶段文件完成状态和负责人。
- 未确认内容必须进入 `01-requirement/open-questions.md`。
- 不适用阶段必须写明“不适用原因”，不得删除目录。
