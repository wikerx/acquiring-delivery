# 技术设计

## 文档目的

定义需求的系统方案、模块边界、接口契约、数据流、状态流、幂等、安全和发布设计。

## 填写责任

技术负责人主写；受影响模块负责人评审；测试和安全负责人确认验证口径。

## 输入资料

- 已确认 PRD、业务规则、验收标准和影响分析。
- 现有代码、配置、README、AGENTS、质量门禁和测试基线。

## 必填内容

- 总体方案和不处理范围。
- 后端服务边界、分层设计、接口调用链和异常处理。
- 前端应用、路由、菜单、按钮、接口权限和状态管理影响。
- SDK 兼容性设计；仅适用于对外接口或协议变化。
- 金额币种、状态机、幂等、RocketMQ、Redis、定时任务、渠道路由、安全、配置、数据库、迁移、发布和回滚设计。
- 测试策略和灰度/发布策略。
