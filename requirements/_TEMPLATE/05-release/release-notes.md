# 发布说明

## 文档目的

面向业务、研发、测试、运维和支持团队说明本次发布内容、影响、验证结果和风险。

## 填写责任

发布负责人维护；需求、研发、测试和业务负责人确认。

## 输入资料

- PRD、变更清单、测试结果、代码审查、部署计划和发布检查清单。

## 必填内容

- 需求编号、版本、发布时间、发布范围、变更摘要。
- 对管理系统、商户系统、收银台、OpenAPI、SDK、配置、权限、数据库、渠道和回滚的影响说明。
- 验证结果、已知问题、风险和支持说明。
