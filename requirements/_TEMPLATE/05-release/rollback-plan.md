# 回滚方案

## 文档目的

定义发布失败、指标异常或安全风险触发时的回滚策略、步骤和验证方式。

## 填写责任

发布负责人主写；研发、运维、测试和业务负责人确认。

## 输入资料

- 部署计划、配置清单、数据库设计、变更清单、测试结果和监控指标。

## 必填内容

- 回滚触发条件、决策人、执行人和沟通渠道。
- 应用、前端资源、SDK 版本、配置、数据库、任务、MQ/Redis 的回滚策略。
- 回滚后验证、数据一致性检查和补偿方案。
