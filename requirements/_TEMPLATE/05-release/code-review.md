# 代码审查

## 文档目的

记录需求代码审查范围、发现的问题、修复情况和剩余风险。

## 填写责任

代码审查负责人维护；开发负责人修复；测试和发布负责人复核高风险问题。

## 输入资料

- 变更清单、Git diff、技术设计、测试结果和质量门禁。

## 必填内容

- 审查范围、文件、模块和分支。
- 后端分层、金额币种、状态机、幂等、SQL、OpenAPI 安全、敏感日志、前端权限、SDK 兼容性、配置和回滚风险。
- 问题优先级、处理结论和复核结果。
