# SDK 任务

## 文档目的

记录 SDK 是否适用及适用时的公共 API、模型、协议、安全、兼容性和发布任务。

## 填写责任

SDK 负责人维护；OpenAPI 后端负责人、安全负责人和测试负责人确认。

## 输入资料

- PRD、技术设计、OpenAPI 接口契约、SDK README、配置和安全文档。

## 必填内容

- SDK 适用判断：仅当对外接口、协议、模型、签名/加密、配置、示例或兼容性变化时创建开发任务。
- 公共类、方法、字段、模型、配置项、User-Agent / 版本和示例影响。
- Java 8 兼容性、向后兼容、测试、P3C/PMD 和打包要求。
