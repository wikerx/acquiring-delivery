# 实施计划

## 文档目的

拆分开发任务、顺序、依赖、风险和验证方式。

## 填写责任

技术负责人主写；后端、前端、SDK 和测试负责人确认任务边界。

## 输入资料

- 已确认 PRD、技术设计、接口契约、数据库设计、权限设计、配置设计和验收标准。

## 必填内容

- 开发任务清单、负责人、预计分支、是否需要 Worktree。
- 后端、前端、SDK、数据库、配置、测试和发布依赖顺序。
- 公共 DTO、枚举、数据库实体、根配置变更的评审点。
- 禁止未确认 PRD 或技术设计时开发。
